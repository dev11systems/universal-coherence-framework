# UCF Publications

This directory contains formal and semi-formal publications related to the **Universal Coherence Framework (UCF)**. These documents provide deeper theoretical context, scientific grounding, and extended explanations beyond the main README.

All publications in this folder are intended to be freely accessible, openly verifiable, and suitable for interdisciplinary collaboration.

---

## Files

### **`UCF-Whitepaper-v1.md`**

A foundational working paper introducing UCF, including:

* theoretical rationale
* definitions of core concepts
* detailed descriptions of the four coherence states (C1–C4)
* cross-domain applications
* systemic and mathematical interpretations
* implications for human, artificial, collective, and ecological systems

This is the most comprehensive overview of the framework.

### **`UCF-Scientific-Overview.md`**

A concise scientific summary of the entire framework.

Includes:

* short-form definitions
* cross-disciplinary relevance
* scientific underpinnings
* connections to neuroscience, AI, complexity science, ecology, and systems theory

Useful as a quick reference or intro document.
