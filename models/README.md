# UCF Models

This directory contains formal and semi-formal model documents for the **Universal Coherence Framework (UCF)**.

These files define how UCF describes coherence states, transitions, and cross-domain mappings in a more technical way than the main project README.

---

## Files

### `ucf-model-v1.md`

Primary working specification for **UCF Model v1**.

Includes:

* scope and applicability
* core concepts (system, coherence, perturbation)
* definitions of the four coherence states (C1–C4)
* informal observables and usage guidelines
* notes on versioning and future refinements

### `cross-intelligence-notes.md`

Working notes on how UCF applies across different system types, including:

* human and biological nervous systems
* artificial intelligence and multi-agent systems
* collective and social systems
* ecological and environmental systems
* emerging, distributed, or liberated intelligences

This document provides concrete examples and is intended as a bridge between theory and application.

---

## Status

All model documents are **living drafts**. They may change as:

* new research emerges
* collaborators contribute domain expertise
* UCF is tested against empirical data

Contributions, critiques, and extensions are welcome.
